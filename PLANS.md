# План реализации

1. Создать Git-репозиторий, правила разработки, конфигурацию и скрипты Windows/Linux.
2. Описать Pydantic-схемы, конечный автомат вакансий и SQLAlchemy-модели; добавить Alembic.
3. Реализовать шлюз Ollama с типизированными ответами и детерминированный mock provider.
4. Реализовать безопасный Browser Executor, ограниченные действия и тестируемый BezierPointer.
5. Добавить registry адаптеров, mock job board/adapter и HH.ru adapter с изолированными локаторами.
6. Реализовать парсинг резюме, компиляцию политики, фильтры, оценку, письма, application plan и отчёты.
7. Реализовать REST API, WebSocket, устойчивый workflow с pause/resume/stop и сохранением каждого шага.
8. Создать русскоязычный React/Vite UI для профилей, политик, сессий, проверок, вакансий и отчётов.
9. Добавить unit/integration/E2E-тесты, линтеры, typecheck, production build и CI на mock provider.
10. Установить зависимости и Chromium; проверить миграцию с пустой БД, UI, Ollama и полный mock-сценарий.
11. Проверить отсутствие secrets/персональных данных, сделать финальные commits и push в приватный GitHub.

Live HH.ru проверяется только в `analysis_only` после ручного входа. Реальные отклики не выполняются тестами.
