# Job Application Orchestrator

Локальное веб-приложение для поиска работы: оно хранит профиль и несколько резюме, ищет вакансии в видимом Chromium, передаёт их облачной OpenAI-compatible модели на оценку и помогает управлять критериями, лимитами и ходом сессии.

Приложение не использует скрытые API сайтов. Сайты открываются через Playwright в отдельных постоянных профилях Chromium. Данные и SQLite-база хранятся локально в `data/`.

## Что умеет

- создавать профиль кандидата и несколько резюме вручную;
- импортировать резюме из PDF, DOCX или TXT (после импорта данные нужно проверить; сканированный PDF без текстового слоя не поддерживается);
- выбирать резюме для matching и задавать свободное описание желаемой вакансии;
- искать и оценивать вакансии по задачам, навыкам, опыту, роли, сфере и особым требованиям;
- показывать разбор оценки и генерировать сопроводительное письмо на основе только сохранённых данных;
- вести параллельные сессии на разных площадках, с лимитами, событиями и уведомлениями.

### Две площадки — два сценария

**HH.ru** — поиск, оценка и отправка откликов по заданным правилам и лимитам сессии. CAPTCHA, MFA, тестовые задания, неизвестные вопросы и чувствительные данные требуют ручного решения.

**HireHi** — только сбор подходящих вакансий и PDF-отчёт. Формы не заполняются, отклики не отправляются, отдельный список контактов не ведётся. В отчёт попадают ссылка, маршрут вакансии и найденные контакты, чтобы пользователь сам решил, что делать дальше.

## Быстрый запуск на Windows

Нужны Python 3.11 или 3.12, Node.js LTS и Git.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

Откроется <http://127.0.0.1:8000>. Для разработки с hot reload запустите:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-dev.ps1
```

В dev-режиме интерфейс доступен на <http://127.0.0.1:5173>, API — на порту 8000. `bootstrap.ps1` создаёт `.venv`, устанавливает зависимости и Chromium Playwright, собирает frontend и применяет миграции SQLite. Production-порт можно изменить: `scripts/start.ps1 -Port 8100`.

Файл `.env` для запуска не нужен и создавать его не следует. Приложение стартует со встроенными безопасными значениями, а Base URL, API-ключ и имя модели задаются и сохраняются в разделе **Модель**. Переменная `JAO_DATABASE_URL` поддерживается только как явный одноразовый override для запуска миграций (например, изолированной тестовой базы); она не заменяет настройки модели и не требует `.env`.

## Первый запуск и повседневный поток

1. Откройте вкладку **Модель**, укажите HTTPS Base URL облачного OpenAI-compatible API, API-ключ и модель. Ключ шифруется Windows DPAPI и не возвращается через API или логи.
2. В **Профиле** создайте личный профиль, затем создайте или импортируйте резюме. Проверьте импортированные поля и отметьте резюме **Передавать модели**.
3. В **Сессии** выберите HH.ru или HireHi, задайте лимиты и коротко опишите желаемую вакансию. Нажмите запуск.
4. При первом входе нажмите **Открыть браузер** и авторизуйтесь в отдельном профиле Chromium. Если сайт запросит CAPTCHA или другой неподдержанный шаг, выполните его вручную и продолжите сессию.
5. В **Вакансиях** просмотрите оценки, объяснения и сопроводительные письма. Для HireHi скачайте PDF-отчёт; ход HH.ru-сессии контролируйте по статусам и событиям.

## Ограничения и безопасность

- Публичный Base URL должен быть HTTPS; HTTP допускается только для уже настроенного локального loopback-gateway.
- Production использует облачный OpenAI-compatible API; mock-провайдер предназначен для тестов и демонстрации.
- При импорте модель получает извлечённый текст импортируемого резюме; при оценке и подготовке письма — личный профиль, выбранные резюме и данные вакансии. Она не должна придумывать опыт, контакты, даты или достижения.
- Не добавляйте в репозиторий `.env`, ключи, резюме, cookies, browser profiles, базу и отчёты: рабочие данные находятся в `data/`.
